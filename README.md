## Backend Engineering & Security

My primary engineering interests are centered around building backend systems that are secure, efficient, and maintainable.

| Area | Focus |
|---|---|
| Authentication | Session-based authentication, JWT, access and refresh tokens |
| Authorization | Role-based access control and resource ownership |
| Application Security | Password hashing, input validation, CORS, security headers |
| API Protection | Rate limiting, brute-force protection, request restrictions |
| Performance | Caching, concurrency, memory and resource optimization |
| Database Engineering | Data modeling, query optimization, transaction management |
| Architecture | Separation of concerns, modularity, maintainability and scalability |

I aim to understand not just how to implement a feature, but also its security implications, performance characteristics, trade-offs, and behavior as application usage grows.

## Featured Projects

### 01. Workspace Service

**Secure Backend Application**

A backend application focused on authentication, authorization, API protection, and security-conscious engineering.

**Engineering Highlights**
- Spring Security-based authentication and JWT.
- BCrypt password hashing and credential protection.
- Access and refresh token management.
- Role-based authorization and resource ownership enforcement.
- API rate limiting using Bucket4j and Caffeine.
- Request-size restrictions and input validation.
- CORS configuration and security headers.
- Centralized error handling and environment-based secret management.
- Documented architectural decisions and security trade-offs.

**Technology:** Java 17, Spring Boot, Spring Security, JWT, PostgreSQL, JPA, Bucket4j, Caffeine, Maven.
